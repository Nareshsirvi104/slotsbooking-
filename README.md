A simple Slot Booking Application built with React.js on the frontend, Node.js + Express on the backend, and MySQL as the database. Users can view available slots and book them in real-time.
Features:-
- View all available slots in a grid layout.

- Book a slot with a single click.

- Disabled buttons for already booked slots.

- Real-time update of slot status.

- Responsive and user-friendly UI.
